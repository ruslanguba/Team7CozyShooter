Team7CozyShooter (Dreamville)

Dreamville is a 3D third-person shooter prototype developed in Unity as a team project during a 1-month student game development program.

🎮 About the Game

Dreamville is a cozy 3D third-person shooter set in a surreal dream world.
The player controls a character in a dream-themed city, moving freely in 3D space while fighting nightmare enemies. The game combines shooting mechanics, 3D movement, and interactive environments to create a playful, immersive experience.

The project was developed by Team 7, including designers, artists, and programmers, giving it a fully collaborative structure and polished 3D gameplay feel.
